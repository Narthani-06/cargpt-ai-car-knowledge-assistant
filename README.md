# CarGPT – AI Car Knowledge Assistant

CarGPT is a Generative AI-powered chatbot designed to answer car-related questions using a custom car knowledge base.

## Features

- AI-powered car information chatbot
- Custom car knowledge base
- Car specifications and feature search
- Car comparison
- Retrieval-based information search
- Prompt engineering
- RAG-based response generation
- User-friendly chatbot interface

## Technologies Used

- React
- JavaScript
- Python
- FastAPI
- Generative AI
- Large Language Models (LLM)
- Retrieval-Augmented Generation (RAG)
- HTML & CSS

## How It Works

The user enters a car-related question. The system searches the custom knowledge base for relevant information and provides the retrieved context to the AI model. The AI then generates a clear response based on the available information.

## Example Queries

- Tell me about Hyundai Creta
- Compare Hyundai Creta and Kia Seltos
- Which cars have automatic transmission?
- Tell me about Tata Nexon
